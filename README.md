# remind-me

reminder app for windows/linux/android

## Installation

### Windows

Download `Remind Me-Setup.exe` from the [latest Release](https://github.com/Delfi-CH/remind-me/releases/tag/latest) and run it.

### Linux

#### Debian

Download `Remind Me.deb` from the [latest Release](https://github.com/Delfi-CH/remind-me/releases/tag/latest) and install it with `dpkg`.

#### Arch Linux

Clone the Repository, go to the `archlinux` directory and run `makepkg`.

```bash
git clone -b publish https://github.com/Delfi-CH/remind-me.git

cd remind-me/archlinux

makepkg -si
```

#### Other Distributions

**Recommended**

Donwload `Remind Me.Appimage` from the [latest Release](https://github.com/Delfi-CH/remind-me/releases/tag/latest), make it executable with `chmod +x` and run it.

Or download `Remind Me.tar.xz` from the [latest Release](https://github.com/Delfi-CH/remind-me/releases/tag/latest), extract it and run `remind-me`.

### Android

Download `Remind Me.apk` and install it.
